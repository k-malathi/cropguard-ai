# CropGuard AI — Demo Flow

## Demo Scenario

A tomato field is being monitored for a possible crop disease outbreak.

> All values shown during this demonstration are prototype/demo data.

## Demo Steps

### 1. Sense
Upload or select a crop image from the Crop Analysis page.

### 2. Detect
The AI Vision module analyzes the image and displays the detected crop issue with a confidence value.

### 3. Analyze
The Risk Intelligence module evaluates:
- Disease severity
- Affected area
- Spread risk
- Short-term risk projection

### 4. Decide
The AI Decision Agent determines the appropriate response category based on the detected risk.

### 5. Contain
The system identifies the affected field zone and displays a localized containment recommendation.

### 6. Alert
A farmer alert is generated with:
- Detected issue
- Risk level
- Affected zone
- Recommended action

### 7. Learn
The outcome can be recorded as feedback for continuous improvement.

## Complete Workflow

Sense → Detect → Analyze → Decide → Contain → Alert → Learn
